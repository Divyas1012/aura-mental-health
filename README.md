🌿 Aura – AI Mental Health Companion

**Aura** is an AI-powered mental wellness web application designed to help users manage everyday stress, understand their emotions, and practice self-reflection in one platform.

✨ Key Features

* 🤖 **AI Companion** – Provides supportive and empathetic conversations.
* 😊 **Mood Diary** – Record moods and identify possible triggers.
* 📔 **Journal** – Write and save personal thoughts and reflections.
* 🧠 **CBT Thought Reframer** – Identify negative thinking patterns and create balanced perspectives.
* 🧘 **Breathing Exercises** – Guided breathing sessions for relaxation.
* 🎧 **Relaxing Soundscapes** – Rain, ocean, and other calming audio experiences.
* 📊 **Mood History** – Track and observe mood patterns over time.

🛠️ Technologies

* HTML
* CSS
* JavaScript
* AI / NLP concepts
* Web Audio API
* GitHub Pages

 🔄 How It Works

**Track Mood → Reflect → Interact with AI → Practice Wellness Activities → Reframe Thoughts → Monitor Progress**

🎯 Objective

The goal of Aura is to combine **AI, mood tracking, journaling, mindfulness, and CBT-inspired techniques** into a simple and accessible digital wellness platform.

> **Note:** Aura is a wellness-support application and is not a replacement for professional mental-health care.
